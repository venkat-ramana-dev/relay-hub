COMPARISON / TAKEAWAY
---------------------
- Both runs passed the configured http_req_failed < 1% threshold.
- Run 2 had higher aggregate throughput: 72.82 req/s vs 62.02 req/s.
- Run 2 had lower median and p95 HTTP latency: 20.53 ms / 49.08 ms vs 24.10 ms / 54.51 ms.
- Average latency is much higher than median/p95 because a small number of requests had very long delays.
- Maximum latency values are outliers, not representative normal latency.
- These are local-machine benchmark results, not a claim of production capacity.
- No p99 was collected in the default k6 summary.
